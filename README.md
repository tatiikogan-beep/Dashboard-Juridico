# Dashboard Jurídico — Imaculada Gordiano Sociedade de Advogados

Painel executivo para geração automatizada de dashboards jurídicos a partir de planilhas exportadas do sistema de gestão.

## 🔗 Acesso

[**Abrir Dashboard**](https://SEU_USUARIO.github.io/NOME_DO_REPOSITORIO)

---

## 📋 Planilhas necessárias

| Planilha | Campo-chave de cliente | Obrigatória |
|---|---|---|
| `Portal IGSA – Processos` | `Cliente principal` | ✅ |
| `Portal IGSA – Serviços` | `Cliente principal` | ✅ |
| `Portal IGSA – Audiências / Prazos / Perícias` | `Cliente Processo` | Opcional |
| `Portal IGSA – Decisões` | coluna 3 (Cliente) | Opcional |

## ▶️ Como usar

1. Abra o link do portal
2. Carregue as planilhas exportadas do sistema
3. Carregue o logo do cliente (opcional)
4. Informe o(s) nome(s) do(s) cliente(s) separados por `;`
5. Clique em **Gerar Dashboard**

## 🔒 Privacidade

Todo o processamento é feito **localmente no navegador** — nenhum dado é enviado a servidores externos.
